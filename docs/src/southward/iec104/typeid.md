## 1. 完整的点位身份

一个 Channel 可承载多个 CA。Device 指定 `ca`；Point 使用 `typeId` 和完整 24-bit `ioa`（`0..16777215`）。只有站址、监视 TypeID 和 IOA 都匹配，数据才进入对应点位。相同 IOA 的不同 TypeID 是不同匹配项，不能用缩短的 IOA 或相邻 TypeID 代替。

这不意味着它们是独立物理控制对象：控制排他按 CA/IOA 维持，不能通过改变命令 TypeID 绕过未决操作或重复选择同一目标。

## 2. 状态、数值与质量分别建模

| 类型 | 必须保留的含义 | 推荐 DataType |
| --- | --- | --- |
| M*SP*\* | 单点 Boolean，质量独立 | Boolean |
| M*DP*\* | `0` 中间态、`1` OFF、`2` ON、`3` 不确定 | UInt8 |
| M*ST*\* | 有符号 `-64..63`；transient 与位置独立 | Int16 |
| M*BO*\* | 无符号完整 32-bit 位模式 | UInt32 |
| 归一化 M*ME*\* | 协议单位为有符号 raw count 除以 `32768` | Float32 / Float64 |
| 标度化 M*ME*\* | 有符号 16-bit 值 | Int16 / Float64 |
| 短浮点 M*ME*\* | IEEE754 短浮点 | Float32 / Float64 |
| M*IT*\* | 有符号 32-bit 计数；SQ/CY/CA/IV 不是数值位 | Int32 / Int64 |

双点的中间态/不确定不能当成 OFF。累计量的符号不能丢失；单位、倍率和溢出语义由实际设备映射决定，不能仅凭类型名假定为电能单位。保护事件的 EI 表示历时无效，不是测量溢出。

品质详情、Test、源时间标志与值独立观察。IV、非当前、替代、闭锁、溢出等事实不能因类型转换而变成“正常”。CP24/CP56 的原始时间事实与网关接收时间不同；时区/世纪没有明确配置时，不制造完整 UTC 源时间。

## 3. 写入使用协议单位

WritePoint 根据支持的监视类型选择对应命令；Action input 配置命令 TypeID。每个输入分别设置 IOA、数据类型及 `controlMode`。完整命令表见[驱动概览](./index.md#_4-过程控制)。

- 单命令：Boolean 或精确 `0/1`。
- 双命令：精确 `1` OFF、`2` ON；`0/3` 不作为有效控制。
- 步进命令：精确 `1` LOWER、`2` HIGHER；不能把绝对位置当方向。
- 归一化设点：有限 `[-1, 32767/32768]`，使用 Float64 表达协议单位；`0.5` 对应 raw count `16384`。
- 标度设点：精确有符号 16-bit 整数。
- 短浮点设点：可表示为有限短浮点的数值。
- 位串：精确无符号 32-bit 整数，UInt32 可表达 `4294967295`；仅支持 `direct`。

Core 的配置逆变换只执行一次。不要再次缩放、按模取状态或截断分数。Boolean 不能用来代替双命令/步进命令，字符串或 byte blob 也不代替数字。

## 4. 监视事实与操作结果

链接 ACK 不等于应用确认，正选择也不等于执行。操作页的协议接受、终结、未知以及独立监视值分别解释。重复业务意图查询原操作，不靠重连、读回相同值或重新创建 Action 来推断/重放控制。

CA 的 metadata 范围为 `1..65535`；需要唯一响应者的控制和 GI/CI 只使用 `1..65534`。GI/CI 使用通道的只读召唤入口，不占用一个伪造的写点或 dummy Action。
